# 🇿🇦 R200 Demo Note Generator

A polished fictional R200 banknote-style generator built with **HTML, CSS and JavaScript**.

## Features

- Random DEMO serial numbers
- Animated guilloche/security-style patterns
- Holographic-style strip
- QR code
- Responsive mobile design
- Generate New Note button
- Download PNG button
- No real currency reproduction
- Clearly marked **DEMO — NOT LEGAL TENDER**

## Run locally

Open `index.html` in a browser.

For the QR code, the page loads QRCode.js from a CDN, so an internet connection is needed for that feature.

## GitHub Pages

1. Create a GitHub repository.
2. Upload `index.html`, `style.css`, `script.js` and `README.md`.
3. Go to **Settings → Pages**.
4. Select the `main` branch and `/ (root)`.
5. Save.
6. GitHub will provide the live site URL.

## Important

This project is intentionally fictional and is not intended to reproduce, counterfeit, or imitate an actual banknote. It is clearly marked as a demonstration and **not legal tender**.
